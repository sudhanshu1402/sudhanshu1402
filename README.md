## How I work

- **Boring tools first.** Novelty is a cost you pay at 3am.
- **Design for the failure.** Retries, partial writes, a process dying mid-transaction. That's usually where the real design is.
- **If I can't see it, I don't trust it.** The runbook and the traces come before "done".
